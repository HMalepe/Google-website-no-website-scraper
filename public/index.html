          Businesses whose only "website" is an Instagram page, ranked by followers and engagement. A big, engaged audience with no site of their own is your strongest pitch: proven demand, no storefront they own. Uses Meta's official API (free), so only public business/creator accounts can be looked up.

          Connect your Instagram professional account
          1. Switch an Instagram account you own to a Business or Creator account and link it to a Facebook Page.
          2. At developers.facebook.com, create a free app and add the Instagram API (with Facebook Login).
          3. In the Graph API Explorer, generate a token with instagram_basic, pages_show_list and pages_read_engagement, then exchange it for a long-lived token (lasts about 60 days).
          4. Find your Instagram account ID: in the Explorer, query me/accounts?fields=instagram_business_account.

          Meta changes its review rules often: if lookups of other accounts fail, the app may need Meta's app review for Business Discovery.
